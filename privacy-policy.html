Apple Reminders → Google Tasks Sync

Last updated: March 31, 2026

Overview

Apple Reminders → Google Tasks Sync ("the application") is a personal, single-user macOS utility developed and operated by Alex Bisson solely for personal use. It is not a commercial product and has no end users other than its developer.

Data collected and processed

The application accesses the following data exclusively on the owner's device:

  • Apple Reminders: reminder titles, notes, and due dates from the configured list(s).
  • Google Tasks: task titles, notes, due dates, and completion status in the configured Google Tasks list.

This data is read and written solely to perform the sync between the two services. No data is stored beyond what is already present in Apple Reminders and Google Tasks.

Data sharing

No personal data is shared with any third party. All processing occurs locally on the owner's Mac. The only external communication is with Google's APIs, which is necessary to read and write tasks in the owner's own Google Tasks account.

Google API scopes used

The application requests the following OAuth scope:

  • https://www.googleapis.com/auth/tasks — used to create, update, and complete tasks in the owner's Google Tasks account.

Access tokens are stored locally in a token.json file on the owner's machine and are never transmitted to any server other than Google's OAuth endpoints.

Data retention

The application does not retain any personal data beyond what exists natively in Apple Reminders and Google Tasks. A local state.json file stores a mapping of reminder IDs to Google Task IDs for sync tracking purposes only; it contains no personal content.

Contact

This application is for personal use only. For questions, refer to the source code on GitHub.
