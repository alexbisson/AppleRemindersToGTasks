A personal macOS utility by Alex Bisson

Personal Tool

What is this?

This is a lightweight macOS background service that performs a one-way sync from Apple Reminders to Google Tasks. It is a personal, single-user utility — not a commercial product or public service.

How it works

  • Reads incomplete reminders from a configured Apple Reminders list using the native EventKit framework.
  • Creates or updates corresponding tasks in a Google Tasks list via the Google Tasks API.
  • Marks Google Tasks as complete when the corresponding reminder is completed or deleted in Apple Reminders.
  • Runs automatically every 10 minutes as a macOS launchd background agent.

Google API usage

This application requests the following Google OAuth scope:

https://www.googleapis.com/auth/tasks Used to create, update, and complete tasks in the owner's Google Tasks account.

No data is shared with any third party. All processing happens locally on the owner's Mac.
